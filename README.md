# **ayaan-lib-js**

## **Quick Start**
> Note: This is in pre-alpha so there is no point to using this.

> Note: This uses ES6 modules so it can not be opened directly as a file (`file://`). You can use a local server.

Keep ayaan-lib-js in your project and import any modules that you want to use.
Every module imports its own dependencies so you do not have to worry about that.
You can keep or delete `test/` and `benchmark/`; the lib does not need them. I would delete them.

## **Core Goal**
Make a personalized JS utility lib that helps with managing different screens,
and providing other useful tools like buttons or math utilities.
It should also have a fun vibe while being useful.
The lib should also follow a modular design; you import the things you need and ignore the rest.

## **Why**
If I am being honest: it is because I thought it would be fun and it is!
I wanted to learn, which I did in plenty while doing this project so that is very good.

## **Current State**
Very much Pre-Alpha. It is quite early and the majority is still left to be built.
